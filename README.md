# Python Programming 🐍

A beginner-friendly collection of Python programs covering fundamentals, problem-solving, data structures, functions, OOP, file handling, and mini projects.

## Contents
Programs are kept in one folder and numbered in learning order.

- Python fundamentals, input/output, data types, and operators
- Conditional statements and loops
- Number and pattern programs
- String and list operations
- Functions and recursion
- Object-oriented programming
- Exception and file handling
- Mini projects

## Run a program
Make sure Python 3 is installed, then run:

```bash
python 01_hello_world.py
```

Some programs ask for input in the terminal.

## Purpose
To practise Python, strengthen logical thinking, and build programming confidence.

**Learning by coding. Practising by building.**
